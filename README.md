# AI Power Users — Course Materials

Open course materials for the **Global Builders Club** *AI Power Users* program:
a one-week, hands-on intensive that turns anyone — no coding required — into a
confident, private-by-default power user of modern AI.

Every session is streamed live on YouTube and runs alongside a Luma cohort. All
materials here are free and open, and every tool we use is free and (where
possible) open source.

## The program at a glance

- **5 days** — Monday to Friday
- **3 hours per day** — three 45-minute modules, each followed by a 15-minute break
- **15 modules total**
- **Live** on YouTube, with a Luma cohort for peer learning, exercises, and peer-evaluated assessments

See [`course-overview.md`](./course-overview.md) for the full 15-module map and
the course values.

## How to use these materials

- **Watching the stream?** Open the module's `student-guide.md` and follow along.
- **Instructor / host?** Use `agenda.md` and `livestream-script.md`.
- **Running the cohort?** Post `luma-description.md` on Luma and use `quiz.md`
  for the peer-evaluated check at the end.

## Module 1 — Agent & Private AI Second Brain Setup

Day 1 · Module 1 of 15 · 45 minutes. We install the whole private-AI toolkit and
wire it together: local speech-to-text, a Markdown "second brain," a private
LLM, and a terminal AI agent that lives inside your notes — finishing with your
first custom skill, a daily standup with your agent.
