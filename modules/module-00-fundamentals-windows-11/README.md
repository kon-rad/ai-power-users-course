# Module 0: AI Power User Fundamentals for Windows 11 Users

**Pre-course session. 60 minutes. Live on YouTube. From Argo, hosted by Konrad Gnat.**

The first hour of the course, for anyone who has never used a terminal. No AI, no
agent, no coding. This is the hour that makes every session after it make sense.

## The spine: one folder, four windows

Everything points at a single folder, `C:\Users\<you>\Documents\secondBrain`.

```
                C:\Users\you\Documents\secondBrain
                   projects  areas  resources  archives
                                  |
        +------------------+------+------+------------------+
        |                  |             |                  |
   File Explorer      Windows        Obsidian            VS Code
   browse it          Terminal       read and link it    inspect the files
                      create it
```

Not four applications to learn. Four windows onto one folder.

## The tools

| Tool | Role | Download |
|---|---|---|
| **Windows Terminal** | Type commands instead of clicking | Ships with Windows 11 |
| **File Explorer** | The same folders, with a mouse | Ships with Windows 11 |
| **Handy** | Talk instead of type, in any app, offline | https://handy.computer |
| **Obsidian** | Read, link, and think in your notes | https://obsidian.md |
| **VS Code** | Look at what is actually in the files | https://code.visualstudio.com |

## Learning objectives

By the end of this module you can:

1. Say what a terminal is, where it came from, and why it outlived the mouse.
2. Explain what open source means, and why the file format matters more than the licence.
3. Navigate the filesystem from the command line and read any path out loud.
4. Create folders and files from the terminal and find the same ones in File Explorer.
5. Copy, cut, paste, switch windows, switch tabs, and open a new tab by keyboard.
6. Rename a file and pin a folder to the File Explorer sidebar.
7. Open a terminal in any folder from File Explorer, and File Explorer from any terminal.
8. Set up Handy with a Whisper model, a push-to-talk key, and recover text from history.
9. Open a folder as an Obsidian vault and organise it with PARA.
10. Use links, backlinks, and canvas, see all file types, and install a community plugin.
11. Open the same folder in VS Code and install an extension.

## Speech to text in your own language

Use a **Whisper** model in Handy. Whisper supports 99+ languages, including
Cambodian (Khmer). Whisper Large is the most accurate, Whisper Turbo and Small
are faster on older machines.

## Before the session

Install these three from their websites, and **open Handy once and download a
Whisper model.** That download is over a gigabyte and will not finish on venue
wifi with thirty people trying at once.

- Handy: https://handy.computer
- Obsidian: https://obsidian.md
- VS Code: https://code.visualstudio.com

You also need Windows 11, 8 GB RAM, and 5 GB free disk.

Full instructions are in [`student-guide.md`](./student-guide.md).
