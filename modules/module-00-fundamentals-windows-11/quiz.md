# Module 0 Quiz

**Peer-evaluated.** Six multiple choice, three open questions, one practical
exercise. Answer the open questions in your own words. A peer scores them against
the rubric at the bottom.

---

## Part 1: Multiple choice

**1. You type `pwd` and press Enter. What happens?**

- A. It deletes the folder you are in
- B. It prints the folder you are currently standing in
- C. It creates a new folder
- D. It asks for your password

**2. You want to dictate in Khmer with Handy. Which model do you choose?**

- A. Any model, they all support every language
- B. The smallest one, because speed is what matters
- C. A Whisper model, because Whisper supports 99+ languages including Khmer
- D. It cannot be done offline

**3. In an Obsidian note you type `[[Terminal]]`. What does that do?**

- A. Nothing, it is just text in brackets
- B. It runs a terminal command
- C. It hides the word from the reader
- D. It creates a link to a note called Terminal, and creates that note if it does not exist

**4. You are in a terminal, standing in your `secondBrain` folder, and you run `start .` What happens?**

- A. It starts an AI agent
- B. File Explorer opens showing that same folder
- C. It restarts the terminal
- D. It starts a new file

**5. What is an Obsidian vault?**

- A. An encrypted container that locks your notes
- B. A cloud account where your notes are stored
- C. A normal folder on your disk that Obsidian has been pointed at
- D. A paid feature for backing up notes

**6. You have text selected in the terminal and you press `Ctrl+C`. What happens?**

- A. It stops the running command
- B. It copies the selected text
- C. It closes the terminal
- D. It pastes from the clipboard

---

## Part 2: Open questions, scored by a peer

**7. Explain to someone who has never used one what a terminal is, and why it still exists in 2026.**

*Looking for: some sense that it was originally a physical machine and the window
is now an emulator, plus at least one real reason it survived. The strongest
answers get to the idea that a command can be saved, repeated, and shared, and a
click cannot.*

**8. You dictated a good paragraph with Handy, then the window closed before you saved it. Where is that text, and how do you get it back?**

*Looking for: the History tab in Handy's settings sidebar, and that you can copy
any past transcription back to the clipboard. A bonus if they mention the audio
player, or that History Limit controls how long entries survive.*

**9. Give one example from your own life of something that is an Area, and a Project that lives inside it. Explain why one is which.**

*Looking for: a genuine personal example, not a textbook one. The Project must
have an end and an outcome. The Area must be ongoing with no finish line. The best
answers show they understand PARA sorts by how soon you must act, not by subject.*

---

## Part 3: Practical exercise, checked by a peer

**10. Four windows, ten seconds.**

Sit with your peer. Starting from a clean desktop, open your `secondBrain` folder
in all four windows: File Explorer, Windows Terminal, Obsidian, and VS Code.

Your peer times you and checks one thing: **did you use the mouse to switch
between windows?** If you did, you have not finished the homework.

**11. Backlink check.**

Show your peer your Graph view. They pick one note and ask you: what links to
this, and what does it link to? Answer without opening the file, using only the
Backlinks and Outgoing links panels.

---

## Peer scoring rubric

Score each open question 0 to 3.

| Score | Meaning |
|---|---|
| **0** | Not answered, or copied straight from the guide with no understanding |
| **1** | Gets the surface fact right but cannot explain why it is true |
| **2** | Correct and explained in their own words |
| **3** | Correct, in their own words, and connected to something outside the question. A real example, a consequence, or a case where it would matter |

**Give one specific piece of feedback with every score.** Naming what was good is
worth as much as naming what was missing. Criticise in private, praise in public.

---

## Answer key, multiple choice

1. **B.** `pwd` prints the working directory.
2. **C.** A Whisper model. Whisper supports 99+ languages, including Khmer.
3. **D.** Double brackets create a link, and the note if it does not exist yet.
4. **B.** `start .` opens File Explorer on the current folder. The `.` means here.
5. **C.** A vault is just a folder. Nothing is imported, converted, or moved.
6. **B.** It copies. In the terminal `Ctrl+C` only stops the running command when
   **nothing** is selected.
