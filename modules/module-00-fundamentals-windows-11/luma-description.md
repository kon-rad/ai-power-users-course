


## Goals

This is a 60 minute class on how to master Windows 11 fundamentals to prepare you to setup and run your personal AI agent on your computer. 

You will learn: 
- how to use the Windows Terminal 
- how to use File Explorer 
- Download and setup Handy - a free Speech to text tool 
- What is open source software 
- Download and setup VS Code - a free code editor 
- Download and setup Obsidian - a free note taking tool 
- Create a set of folders using the PARA method where your AI Agent powered second brain will live
