# Module 0 Agenda: Run of Show

**Pre-course session. 60 minutes. No break.**
Theme: one folder, four windows.

| Time | Segment | What happens | Attendee action |
|---|---|---|---|
| 0:00 to 0:03 | **One folder, four windows** | Show the finished state. Four windows on the same folder, change a file in one, watch it change in the others. | Open the student guide |
| 0:03 to 0:08 | **Terminal history and open source** | Teletype, glass terminal, emulator. A click cannot be saved, a command can. Open source in one line, then: what happens to your files if the company dies. | Watch |
| 0:08 to 0:20 | **The terminal, hands on** | Read the prompt. `pwd`, `ls`, `cd`, `cls`. Read a path out loud. **Tab completion and up arrow, taught hard.** `Ctrl+C` stops things. Build `secondBrain` and the four PARA folders. OneDrive, always keep on this device. `ni`, `cat`, `cp`, `mv`, `rm`. Tabs and split panes. | Build the folder |
| 0:20 to 0:29 | **Windows shortcuts and File Explorer** | **Copy, cut, paste, undo**, and the terminal gotcha where `Ctrl+C` only copies when text is selected. **Alt+Tab** for application windows, **Ctrl+Tab** for tabs, **Ctrl+T** for a new tab, `Win+Left` and `Win+Right` to snap. Then File Explorer: turn on file name extensions and hidden items, **F2 to rename a file**, **right-click Pin to Quick access** to pin a folder to the sidebar. Finish with the bridge: Open in Terminal, and `start .` back the other way. | Follow along |
| 0:29 to 0:33 | **The three apps** | Confirm Handy, Obsidian and VS Code are installed from their websites. What installing does, and what PATH is, using `code --version`. One line on what each app is for. | Verify installs |
| 0:33 to 0:41 | **Handy** | Pick a **Whisper** model, 99+ languages including Khmer. Custom Words and post-processing. Set a push-to-talk key. Dictate into the terminal, then Obsidian, then a browser. The History tab and getting lost text back. | Pick a model, set a key, dictate |
| 0:41 to 0:51 | **Obsidian** | Open the same folder as a vault, nothing is imported. PARA, sorted by actionability not subject. **Detect all file extensions.** `[[Links]]` and `![[embeds]]`, and that linking to a note that does not exist creates it. **Backlinks and unlinked mentions.** **Canvas**, and the rule: content in notes, relationships on the canvas. Then **turn off Restricted Mode and install the VSCode Editor community plugin**, and configure its file extensions. | Open vault, make two linked notes |
| 0:51 to 0:55 | **VS Code** | `code .` from the terminal. Obsidian shows your thinking, VS Code shows the files. Install Markdown All in One. Then `` Ctrl+` `` for the built-in terminal, already in the folder. | Open folder, install extension |
| 0:55 to 1:00 | **Write the Module 0 note** | **In Obsidian, create a folder `ai-power-users` inside `2-areas`, and a note inside it called `module-00`.** Fill it in live, partly dictated with Handy: the terminal commands, the copy and paste keys, the Windows and tab shortcuts, File Explorer, Handy, Obsidian, VS Code. Show the file appear in File Explorer and VS Code. Recap, homework, quiz. | Create the folder, the note, and write it |

## Contingency

- **Protect Handy and Obsidian.** Those are the two segments people came for.
- **Cut first:** the canvas demo, the VS Code extension install, and the terminal
  history down to one line.
- **Never cut:** the final note. Creating `2-areas/ai-power-users/module-00.md`
  live is the artifact of the session and the thing they take home.
- **Graph view looks like nothing** with two notes. Have a mature vault ready on a
  second machine for that shot.
- If a machine cannot run any Whisper model, that student is limited to
  English-only CPU models. Say it straight, move on, help in the break.
