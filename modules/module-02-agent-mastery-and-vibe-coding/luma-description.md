## Full description

This is Module 2 of AI Power Users, a free hands-on live course from Argo.

In Module 1 you built a private AI second brain and wrote your first agent skill by hand.
You never have to do that again.

This session has two halves. Both run on the same idea: you describe, the agent builds.

**First, your agent builds its own tools.** One brief, three skills:

**/model-research** researches the entire AI model landscape once a week. Text, image,
video, voice, speech-to-text, music. Live pricing, ranked, written into your notes. No
more "best AI tools" listicles.

**/switch-models** moves between four models in one command: private, cheap, frontier, and
the best coding model. It stops you before you send client data to a public provider.

**/spend-tracker** tracks exactly what your AI usage costs. It remembers what it already
counted, so every run picks up where the last one stopped.

**Then your agent builds a client's website.** We take a real local business, a fence
installation company, from a blank folder to a live deployed site in one sitting:

1. Set the goals. What must this achieve, and how would we know it failed?
2. Build the knowledge base. Interview the client, then let the agent look at their photos
   and write the alt text and a shot list.
3. Design the layout and functionality. You describe it out loud, the agent writes the spec.
4. Pick the architecture, then make the AI argue against its own recommendation.
5. Approve the plan. The moment a non-programmer gets their power back.
6. Build it with the best coding model, using the real photos.
7. Prove it works. Evidence, not assurances.
8. Git, deploy, live URL. On camera, on a phone.

An agency quotes this at $4,000 to $8,000 and six to eight weeks. We do it in about an
hour, and hosting is free.

**By the end you will have:**

- Three agent-built skills, wired into your standup on a weekly cadence
- A tuned SOUL.md, your agent's personality, and you will know what it costs per message
- A complete client knowledge base: goals, brief, image inventory, layout, architecture
- A real website, on a real URL, that you can show someone
- Git set up, so nothing you build is ever lost

**Who it is for:** anyone who finished Module 1, or anyone with a working AI agent.
No coding experience required.

**The honest part:** what we build in an hour is an excellent starting point, not a
finished client delivery. Real client work adds their photos, their copy, their domain and
revisions. But the hour we save is the hour of building, which was never the valuable hour.
The valuable hour is working out what to build, and that is where we spend most of the time.

**Format:** one live session, about 110 minutes, with a break in the middle. Live on
YouTube.
